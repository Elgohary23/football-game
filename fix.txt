# 📋 Implementation Plan: Realistic Match Scheduling System

## 1. Overview & Goals

Transform the current single-fixture-per-week calendar into a realistic multi-competition scheduling system that mirrors real-world English club football. The system applies **identically** to all teams (player + AI), but the calendar UI exposes only the player's team fixtures.

### Core Objectives
- **2 matches/week baseline rhythm** (League weekend + Cup/European midweek)
- **Boxing Day compressed schedule** (3 matches in 7–8 days during Dec/Jan)
- **FIFA international breaks** (Sept, Oct, Nov, March) — zero matches
- **New UCL format** (Swiss-model league phase + extra qualifying week)
- **Fatigue & injury scaling** based on matches-per-week density
- **Scope**: Applied uniformly to every team across every competition

---

## 2. Match Categorization Model

### 2.1 Two Logical Buckets
Every `Match` row falls into one of two buckets determined by team involvement, **not** a new column:

| Bucket | Definition | Example |
|---|---|---|
| **Player Matches** | `match.home_team.is_player_team == True` OR `match.away_team.is_player_team == True` | Liverpool (user) vs Arsenal |
| **World Matches** | Neither side is the player's team | Man City vs Chelsea (simulated in background) |

> **No schema change required** — the existing `is_player_team` flag on `Team` already disambiguates. We introduce a helper `is_player_match(match)` in `services.py` for clarity.

### 2.2 Scheduling Equality Rule
- **Every team is scheduled by the same engine**, regardless of player/AI status.
- The player's team is *not* given preferential rest days or different cadence.
- This guarantees realism: the user faces the same fixture congestion as any other top-6 side.

## 4. Scheduling Engine

### 4.1 Fixed-Day Cadence (Default Week)

| Day | Slot | Competition |
|---|---|---|
| **Saturday/Sunday** | Weekend | League |
| **Tuesday/Wednesday** | Midweek | European (UCL/UEL) |
| **Thursday** | Midweek alt | UECL or domestic cup |
| **Wednesday** | Midweek alt | Carabao / FA Cup |

**Rule**: 3–4 days minimum between any two fixtures for the same team.

### 4.2 Schedule Patterns

#### Pattern A — Normal Week (most common)
- Sat: League
- Tue/Wed: Cup or European

#### Pattern B — Compressed Week (Boxing Day: Dec 22 – Jan 5)
- Sat: League
- Tue: League or FA Cup replay
- Fri/Sat: League or Cup
- **Fatigue multiplier: ×1.5**

#### Pattern C — Light Week (Aug, post-elimination)
- Sat: League only
- **Fatigue multiplier: ×0.7** (recovery bonus)

#### Pattern D — FIFA Break (Sept/Oct/Nov/March)
- Zero matches for 7–10 days
- National team call-ups (cosmetic only in v1)

### 4.3 Season Structure (40 active weeks)

| Phase | Weeks | Window | Pattern |
|---|---|---|---|
| Pre-season | 1–2 | Aug | Light (C) |
| Autumn block | 3–8 | Sep–Oct | Normal (A) + 1 FIFA break |
| Winter block 1 | 9–14 | Nov–mid-Dec | Normal (A) + 1 FIFA break |
| Boxing Day | 15–18 | Dec 22 – Jan 5 | Compressed (B) |
| Winter break | 19 | Jan (rotating) | Rest |
| Spring block | 20–28 | Feb–Mar | Normal (A) + 1 FIFA break |
| Run-in | 29–38 | Apr–mid-May | Normal (A) + UCL knockouts |
| Season end | 39–40 | Late May | Cup finals |

**Target totals** (team reaching all finals): **60–65 matches**.

## 5. European Competitions (New UCL Format)

### 5.1 League Phase
- **8 matches** per team (was 6) in the Swiss-model phase
- Spread across matchdays 1–8 (Sep → Jan)
- Extra matchday added in the **qualifying week** (last week of Jan) for teams needing the play-off slot

### 5.2 Implementation Hook
In `cup_services.py → seed_continental_league_phase()`:
- Generate 8 fixtures per participant (instead of 6)
- Reserve the **7th qualifying week** as a special matchday slot
- Tag matches with `comp_type = "continental"` and the appropriate color badge

## 6. Fatigue & Injury Scaling

### 6.1 New Helper: `weekly_load(team_id, week)`
Returns the number of matches played by `team` in the given week (0, 1, 2, or 3).

### 6.2 Post-Match Fatigue Update
In `simulation.py → simulate_match()`:

```python
def apply_fatigue(match, multiplier=1.0):
    for player in match.home_team.players + match.away_team.players:
        if player.is_starting:
            player.fitness = max(20, player.fitness - (8 * multiplier))
            # Compressed weeks carry higher injury risk
            if multiplier >= 1.5:
                if random.random() < 0.04:  # 4% injury chance
                    player.injury_days = random.randint(7, 21)
```

### 6.3 Weekly Recovery
In `simulate_day()`:
- Each rest day adds `+3` fitness (cap 100)
- FIFA break weeks add `+15` fitness (full recovery)

## 7. Data Model Changes

### 7.1 New Columns (migration)

**`Match` table**:
- `comp_type` (already used in narrative; promote to a real column with values: `league`, `domestic_cup`, `continental`)
- `matchday` (int, optional — for UCL league-phase numbering 1–8)

**`GameState` table**:
- `season_phase` (enum: `preseason`, `autumn`, `winter`, `boxing_day`, `winter_break`, `spring`, `run_in`, `offseason`)
- `is_fifa_break` (bool, computed from date)

### 7.2 No Breaking Changes
Existing fields (`week`, `date`, `played`, `result`) stay. New columns default to `NULL`/`league` so old saves keep working.
