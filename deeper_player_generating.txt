## 🎯 Task 1: Position-Specific Overall Rating

### 1.1 The Problem

Currently `recompute_aggregates(player)` (from the previous task) derives `attack` and `defense` from a fixed formula per position group (`GK / DEF / MID / FWD`). This is too coarse:
- A `CB` and a `CDM` are both `DEF` in the group, but a CB should be judged almost entirely on `standing_tackle`, `sliding_tackle`, `marking`, `positioning`, `strength`, `jumping`, `defensive_awareness`, while a CDM should be judged on `interceptions`, `standing_tackle`, `passing`, `vision`, `work_rate`, `positioning`.
- A `ST` and a `CAM` are both `FWD / MID`, but a ST should be judged on `finishing`, `shot_power`, `off_the_ball`, `composure`, `acceleration`, `sprint_speed`, while a CAM should be judged on `passing`, `vision`, `ball_control`, `dribbling`, `technique`, `flair`.

The result is that a striker with 95 finishing but 20 interceptions gets a mediocre overall, and a CB with 90 tackling but 15 finishing is unfairly "punished" by finishing.

### 1.3 Aggregate Derivation

Replace `recompute_aggregates(player)` (from the previous task) with a **position-aware** version:

```python
def recompute_aggregates(player: Player) -> None:
    """Compute attack/defense/overall from detailed attributes using the
    position-specific weight tables in POSITION_OVERALL_WEIGHTS."""
    weights = POSITION_OVERALL_WEIGHTS.get(player.detailed_position or "CM")
    if not weights:
        return
    total = 0.0
    for attr, w in weights.items():
        total += (getattr(player, attr, 50) or 50) * w
    player.overall = max(1, min(99, int(round(total))))

    # attack/defense split — derived from the same weights but bucketed
    # into ATTACK_ATTRS / DEFENSE_ATTRS (see config below).
    att_w = sum(w for a, w in weights.items() if a in ATTACK_ATTRS)
    def_w = sum(w for a, w in weights.items() if a in DEFENSE_ATTRS)
    att_raw = sum(getattr(player, a, 50) * w for a, w in weights.items() if a in ATTACK_ATTRS)
    def_raw = sum(getattr(player, a, 50) * w for a, w in weights.items() if a in DEFENSE_ATTRS)
    player.attack = max(1, min(99, int(round(att_raw / att_w)))) if att_w > 0 else player.overall
    player.defense = max(1, min(99, int(round(def_raw / def_w)))) if def_w > 0 else player.overall
```

## 🎯 Task 2: Tier-Bounded Philosophy Distribution

### 2.1 The Rule

Philosophies must be **randomised within a tier band**, never across tiers. Formally:

- **Tier 1 top clubs** (reputation ≥ 85) — the elite. Allowed philosophies: `galacticos`, `possession_domination`, `total_football`, `fluid_attacking`, `tiki_taka`, `gegenpress`. **Forbidden:** `youth_development`, `moneyball`, `park_the_bus`, `route_one`, `counter_attack`.
- **Tier 1 mid clubs** (reputation 70–84) — the ambitious mid-table. Allowed: `tiki_taka`, `gegenpress`, `wing_play`, `high_line_defense`, `moneyball`, `possession_domination`, `balanced`, `fluid_attacking`. Forbidden: `park_the_bus`, `route_one`.
- **Tier 1 lower / Tier 2 clubs** (reputation 55–69) — the pragmatists. Allowed: `counter_attack`, `direct_football`, `wing_play`, `high_line_defense`, `balanced`, `moneyball`, `youth_development`, `route_one`. Forbidden: `galacticos`, `total_football`.
- **Tier 3 / Tier 4 / bottom of Tier 2** (reputation < 55) — the survivors. Allowed: `park_the_bus`, `route_one`, `direct_football`, `counter_attack`, `balanced`, `youth_development`. Forbidden: `galacticos`, `total_football`, `possession_domination`, `tiki_taka`, `fluid_attacking`.

Add to `config.py`:

```python
# Allowed philosophies per reputation band. The philosophy assignment
# picks ONLY from the allowed list for the club's band — this is what
# keeps Barcelona from becoming a "build-and-sell youth project" and
# keeps a League Two club from becoming "galacticos".
PHILOSOPHY_BANDS = {
    "elite":   {  # rep >= 85
        "min_rep": 85,
        "allowed": ["galacticos", "possession_domination", "total_football",
                    "fluid_attacking", "tiki_taka", "gegenpress"],
    },
    "ambitious": {  # 70 <= rep < 85
        "min_rep": 70,
        "allowed": ["tiki_taka", "gegenpress", "wing_play",
                    "high_line_defense", "moneyball",
                    "possession_domination", "balanced", "fluid_attacking"],
    },
    "pragmatic": {  # 55 <= rep < 70
        "min_rep": 55,
        "allowed": ["counter_attack", "direct_football", "wing_play",
                    "high_line_defense", "balanced", "moneyball",
                    "youth_development", "route_one"],
    },
    "survivor": {  # rep < 55
        "min_rep": 0,
        "allowed": ["park_the_bus", "route_one", "direct_football",
                    "counter_attack", "balanced", "youth_development"],
    },
}

def philosophy_band_for(reputation: int) -> str:
    for band_name, spec in PHILOSOPHY_BANDS.items():
        if reputation >= spec["min_rep"]:
            return band_name
    return "survivor"
```

### 2.2 Assignment Algorithm

Rewrite `services.assign_team_philosophy(team)`:

1. Compute the club's band from its reputation.
2. Pick a random philosophy from `PHILOSOPHY_BANDS[band]["allowed"]` — **weighted** so that the most iconic philosophies for that band are more likely (e.g. `galacticos` slightly more likely at Real Madrid / Man City than at Brentford).
3. Copy the profile from `PHILOSOPHY_PROFILES` and jitter each numeric field by ±0.15.
4. Set `season_goal` from the band:
   - elite: `title` or `top4`
   - ambitious: `top4` or `europa`
   - pragmatic: `mid_table` or `europa`
   - survivor: `survival` or `mid_table`
5. Set `patience` and `board_ambition` from the band (elite clubs are less patient, ambitious clubs are more).
6. Persist.

**Crucially:** within a band, the distribution must be **uniformly random** — no club should get a "canonical" philosophy because of its name. Two playthroughs with Real Madrid may roll `gegenpress` and `possession_domination` respectively.

### 2.3 Identity Shift Events (Rare)

The user explicitly wants **rare** identity shifts — a small club suddenly becoming a project, or a big club declining after a run of bad decisions. Add a **season-end** event:

- Add to `config.py`:

```python
# Probability per club per season that its philosophy shifts within its
# band. Kept low on purpose — the user asked for "rare in real life,
# rare in the game".
PHILOSOPHY_SHIFT_CHANCE = 0.03  # 3%

# Probability per club per season that it MOVES band (up or down).
# This is the "small club becomes a project" / "big club declines"
# event. Also kept very low.
PHILOSOPHY_BAND_SHIFT_CHANCE = 0.01  # 1%
```

- Add a new function in `services.py`:

```python
def roll_season_philosophy_shifts(state: GameState) -> list[Message]:
    """Called once per season end. With a very low probability, a club
    shifts its philosophy (within its band) or shifts bands entirely.
    Returns the messages generated (for the inbox)."""
```

- **Within-band shift (3%)**: pick a new philosophy from the *same* band's allowed list, jitter the weights, keep the club's reputation unchanged.
- **Band shift (1%)**: only allowed if the club's performance justifies it. Determine direction from the club's league finish:
  - Top 3 finish + tier-1 club → band up (pragmatic → ambitious → elite).
  - Bottom 3 finish + tier-1 club → band down.
  - Lower-division club that got promoted → band up.
  - Lower-division club that got relegated → band down.
  - **Never** shift more than one band per season.
- When a club shifts band, also nudge its `reputation` by ±5 so the shift is coherent.

This is the ONLY path by which a club can end up with a philosophy outside its initial band, and it's gated to ≤ 1% per season.

## ✅ Acceptance Criteria

1. Every player has an `overall` computed from a **position-specific weight table** (`POSITION_OVERALL_WEIGHTS`), and the weights per position sum to 1.0.
2. A striker's `overall` is **independent** of `interceptions`, and a CB's `overall` is **independent** of `finishing` (test-guarded).
3. `attack` / `defense` remain populated and are derived from the same weight table, bucketed into `ATTACK_ATTRS` / `DEFENSE_ATTRS`.
4. Every club's philosophy is drawn from **only the allowed list for its reputation band** (`PHILOSOPHY_BANDS`). An elite club can never roll `youth_development`; a lower-league club can never roll `galacticos` (test-guarded with 50 iterations).
5. Within a band, philosophies are **randomised** — elite clubs don't all roll the same identity.
6. A **season-end identity-shift event** exists with `PHILOSOPHY_SHIFT_CHANCE = 0.03` (within band) and `PHILOSOPHY_BAND_SHIFT_CHANCE = 0.01` (across bands). It's tested to be **rare** (a forced RNG that never triggers a shift leaves every club unchanged).
7. Band shifts only happen when justified by the club's league finish (top 3 → up, bottom 3 → down) and never move more than one band per season.
8. `evaluate_youngster_surprise_potential(player, philosophy)` exists and rewards high-potential youngsters, especially at `youth_development` / `moneyball` clubs — the foundation for the future "smart signing → 2nd place" scenario.
9. The match engine reads `overall` (not raw `attack` / `defense`) and AI clubs' pressing/tactic are forced from their philosophy at kickoff.
10. `TEMPLATE_SCHEMA_VERSION` bumped; `_ensure_schema_columns()` adds the new columns; old saves migrate cleanly.
11. **All 288+ existing tests still pass**, plus the new tests above.
12. Run `python -m pytest tests/test_backend.py tests/test_frontend.py -q` from repo root — must be **all green** before declaring done.
13. Commit with message `feat: position-specific overalls + tier-bounded randomised philosophies + rare identity shifts`.
