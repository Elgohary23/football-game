You are a Senior Product Designer, UX Architect, and Frontend Engineer working on a Football Manager-style web game.

Your task is to redesign and fully implement the User Interface and User Experience so that EVERY backend system that already exists in the game becomes visible, accessible, intuitive, and fully usable through the UI.

IMPORTANT:
- Do NOT remove any existing functionality.
- Assume the backend APIs, services, routes, models, and business logic already exist.
- Build frontend screens, layouts, modals, dashboards, controls, navigation, tables, cards, visualizations, and interactions for all implemented systems.
- The final product should feel like a premium Football Manager + EA FC Career Mode + Top Eleven hybrid.
- Every implemented feature must be discoverable by the user.
- No backend feature should remain hidden.
- Use modern responsive UI.
- Use clean dark mode football management aesthetic.
- Use professional dashboards, cards, charts, badges, progress indicators, notifications, and advanced management panels.
